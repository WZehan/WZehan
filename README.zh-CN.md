## 目前项目

### 移动应用与 AI

- 📚 **[WIT 图书馆](https://wit-library.wangzehan.cn)** — 我的 2025 届本科毕业设计项目，由 GitHub Copilot 和 ChatGPT 协助构建。Flutter 客户端将多项图书馆服务整合到统一的跨平台体验中，可通过产品页底部的 App Store 链接下载。
- 🎵 **[BiliPod](https://bilipod.com)** — 2026 年 6 至 7 月完全使用 Codex Vibe Coding 构建。客户端采用 Flutter，Supabase 负责用户验证和数据管理，Resend 提供邮箱验证。由于项目可能存在版权风险，目前仅提供有限的测试分发。

### CityU 学生工具

- 🧰 **[CityU Toolbox](https://cityu-toolbox.wangzehan.com)** — 面向香港城市大学学生的实用工具箱。
- 🗓️ **[AIFS Schedule](https://aifs-schedule.wangzehan.com)** — 为 CityU AIFS 专业按 Track 整理的交互式课程表。

### 玩车日志

- 🕰️ **[VW Clock](https://github.com/WZehan/vw-clock)** — 复刻大众中控车机中的三款数字时钟样式。
- 🎛️ **[Sound Visualizer](https://github.com/WZehan/Sound-Visualizer)** — 面向安卓车机的音频可视化软件，兼容 Android 5.1。

### 3D 与 Web 实验

- ✨ **[3DGS Gallery](https://3dgs-gallery.wangzehan.com)** — 汇集个人 3D 高斯泼溅场景的在线画廊。PLY 文件由 Apple 开源的 SHARP 模型生成，并通过 SuperSplat 在网页端交互展示。

### 早期作品
